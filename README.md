# DevOps exam prep

Study system for the SST DevOps & Cloud exam (19 Oct 2026).

| File / folder | What it is |
|---|---|
| `STUDY_PLAN.md` | The day-by-day plan (2 sessions per day) |
| `SYLLABUS.md` | Official subtopics per lecture + coverage status |
| `PROGRESS.md` | Progress tracker: topic status, weak spots, scores |
| `sessions/` | Self-study sessions `01`–`16`, each with an `_ANSWERS.md` key; `MY_ANSWERS.md` for answers; `labs/` for Kubernetes practice YAML |
| `notes/` | `GLOSSARY.md` (all full forms) and `extras_foundations.md` (small-but-important topics) |
