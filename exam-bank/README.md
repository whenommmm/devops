# Exam bank (question bank from `repo-questions/`)

Two files, both in session order 1 → 20:

| File | What's inside |
|---|---|
| [MCQ_BANK.md](MCQ_BANK.md) | All 190 MCQs: question, options, then ✅ the answer and 💡 a one-line explanation |
| [LAB_BANK.md](LAB_BANK.md) | All 57 labs, grouped by session: the commands/config to write, what each line does, how to verify, and a plain summary |
